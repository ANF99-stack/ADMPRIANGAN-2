Atur Base Omset, Dropdown Pemilihan Resto Coverage, Kategori Operasional Resto, serta Batas Jam Check-in Shifting Karyawan.

Pengaturan Jam Check-in KASIR — LAZATTO

Pengaturan dibuat GLOBAL KHUSUS LAZATTO, tidak perlu input satu per satu resto. Sistem memakai data resto Lazatto yang sudah ada untuk menentukan tipe REGULER atau 24 JAM.

Aturan:
• REGULER: Shift 1 default 06:00, Shift 2 default 14:00. Admin tetap dapat mengubah kedua jam tersebut secara global.
• 24 JAM: Admin mengatur Shift 1, Shift 2, Shift 3 secara manual. Ketiga jam wajib diisi.
• Pengaturan hanya berlaku untuk RESTO LAZATTO sesuai tipe resto yang sudah ada. Tidak ada lagi input per resto.
• Resto/brand selain Lazatto tidak menggunakan batas check-in kasir ini dan tetap mengikuti aturan check-in yang sudah ada.
• Pengaturan ini khusus JOB KASIR dan dipakai sebagai batas waktu/indikator keterlambatan check-in Lazatto.
